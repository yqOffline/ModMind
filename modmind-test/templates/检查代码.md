# 提示词模板 · 检查代码（验证 AI 代码）

```
这是我用 [模型名] 求解的代码，请你检查：

1. 逻辑是否正确对应这个模型？（目标函数/约束/指标方向）
2. 有没有数值计算问题？（max 转 min、标准化、ln(0)、数据泄漏、整数约束）
3. 结果是否合理？

【我的数学模型】
[决策变量/目标函数/约束 或 指标体系/权重方法]

【代码】
[粘贴代码]

【请给出】
- 逐条核对结论（对/错 + 原因）
- 如果有错，给出修正后的完整代码
```

## 用户自查清单（拿到代码后过一遍）

- [ ] 逻辑对应：代码的目标/约束是否和我写的数学模型一致？
- [ ] 小数据测试：1-2 个简单数据手算对照
- [ ] 边界情况：全 0、最大值会不会崩？
- [ ] 单位一致：数据单位统一吗？
- [ ] 结果合理：解出来在物理/逻辑上说得通吗？

> 铁律：AI 会一本正经写错，你永远对结果负责。报错原样贴回给 AI 修。
