# 01 · 三类检验（误差 / 灵敏度 / 稳健性）

> 「无检验，不建模」。三类检验单独成节，是国一与普通奖的分水岭。连 2020C 国一都缺灵敏度分析——补上就是亮点。

## 1. 三类检验对比

| 维度 | 误差分析 | 灵敏度分析 | 稳健性分析 |
|------|---------|-----------|-----------|
| 问什么 | 算得准不准 | 参数抖一抖崩不崩 | 换数据/算法结论变不变 |
| 怎么做 | 对比真实值 vs 计算值 | 关键参数 ±5%/±10% 扰动看结果 | 换算法/缩样本/剔异常重复求解 |
| 指标 | RMSE / MAPE / R² / 准确率 / AUC | 结果偏差 % | 结论是否一致 |

## 2. 分题型适配（做哪种检验）

| 题型 | 必做 | 说明 |
|------|------|------|
| 优化 | 灵敏度（参数 ±10%） | 目标系数/约束右端项扰动，看最优解偏移 |
| 统计-分类 | 交叉验证 + 换模型对比 | AUC/F1 + 与 LR/树对比 |
| 统计-回归 | 误差 + 显著性 | RMSE/MAPE + p 值/F 检验 |
| 评价 | 灵敏度（权重 ±10%） | 权重扰动看排名是否翻转 |
| 预测 | 误差 + 精度 | 留测试集 RMSE；GM(1,1) 验 C/P |
| 机理 | 误差 + 参数灵敏度 | 反演参数 ±10% 看拟合退化 |

## 3. 结论句式库（直接贴论文）

- 误差：「RMSE=3.26、MAPE=4.12%，优于基准方法 41%」
- 灵敏度：「参数 ±10% 扰动，结果偏差 <5%，模型稳健」
- 稳健性：「替换 [算法] 重复求解，结论趋势一致」
- 交叉：「VAR(2) 与频率法筛选的品种数均为 29，互为印证」

## 4. 双方法互证（高分亮点）

同一问用**两个独立方法**求解，结果一致即互证（例：模拟退火 vs 贪心、VAR vs 频率法、GM vs ARIMA）。比单一方法的内部检验更有说服力。

## 5. 喂 AI 写检验代码的写法

「对 [模型] 做灵敏度分析：把 [参数名] 分别调 ±5%/±10%，重跑求解，输出各扰动下的 [关键结果] 表格，并计算相对偏差 %。」

## 6. 特殊值 / 对称性校验（B 题机理）

- 对称性：结果关于某参数对称（如 β=180° 时覆盖宽度取极值）
- 极限：参数取 0 / ∞ / 临界值时结果是否符合物理直觉
- 量纲：单位与数值是否自洽
