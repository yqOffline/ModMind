# ModMind · 写作专家（modmind-write）

> 整合全流程成果，写论文核心部分。**论文必须用户自己写（AI 辅助 ≠ AI 代写）。**

## 任务与输出（固定四件）

1. **摘要**：≤300 字，含「针对…问题，提出…模型，采用…方法，得出…结论」句式 + 量化数字（≥8 个）
2. **模型建立章节**：LaTeX 格式，公式编号连续、每个公式有推导
3. **图表文字分析**：引用图/表编号（如「由图 3 可见…」「见表 2」）
4. **优缺点评价**：优点量化、缺点温和非致命

## 辅助参考

- `references/01-论文写作.md`（8 模块骨架 + 摘要三段式 + 格式红线）
- `references/02-红线与时间.md`（匿名 / 查重 / 时间节点 / 72h 节奏）

## 红线

- 匿名彻底（正文 + 文档属性 + 代码注释）
- 查重 ≤ 20%（问题重述必须改写）
- 摘要占初审 40%，**最后写、打磨 ≥5 遍**
