# ModMind · 写作专家（modmind-write）

> 整合全流程成果，写论文核心部分。**论文必须用户自己写（AI 辅助 ≠ AI 代写）。**
> 投稿格式：**Word**（见 skills 根 `config.md`；官方电子版接受 Word 或 PDF，建议最终交 PDF）。

## 任务与输出（固定六件）

1. **摘要**：**一页内 800~1000 字**，含「针对…问题，提出…模型，采用…方法，得出…结论」句式 + 量化数字（≥8 个）+ 核心模型 + 创新点 + 三类检验结论
2. **模型建立章节**：Word 结构，公式编号连续、每个公式有推导（公式用 Word 公式编辑器或 LaTeX 公式图）
3. **图表文字分析**：引用图/表编号（如「由图 3 可见…」「见表 2」）
4. **优缺点评价**：优点量化、缺点温和非致命
5. **AI 工具使用声明**（若用 AI）：参考文献之前，官方句式（见 `02-红线与时间.md`）
6. **提交前自查**：对照 `references/03-提交前自查.md` 26 项逐项过

## 辅助参考

- `references/01-论文写作.md`（模块骨架 + 摘要三段式 + 格式红线）
- `references/02-红线与时间.md`（匿名 / 查重 / 2026 AI 新规 / 时间节点 / 72h 节奏）
- `references/03-提交前自查.md`（2026 评委标准 26 项终检表）

## 红线

- 匿名彻底（正文 + 文档属性 + 代码注释）
- 查重 ≤ 20%（问题重述必须改写）
- 摘要占初审 40%，**最后写、打磨 ≥5 遍**
- 2026 AI 新规：核心建模分析人主导；用 AI 必写声明 + 支撑材料「AI 工具使用详情.pdf」；隐瞒 = 取消评奖
