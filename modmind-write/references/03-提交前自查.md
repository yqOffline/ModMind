# 06 · 提交前自查表（2026 评委标准 26 项）

> 交论文前逐项过。来源：2026 数学建模国赛 AI 全自动自查表（评委评审·标准版）。
> 用法：让 AI 逐维度打「合格 / 存在问题 / 待核实」，给出问题位置 + 整改建议。

## 一、AI 新规合规（4 项，最重，违规 = 取消评奖）

1. 核心建模与核心分析**无人主导痕迹**（模型构建/公式推导/机理/求解逻辑是否 AI 重度主导）
2. 核心写作无 AI 痕迹（摘要/建模分析/结论是否模板化套话、无个性化思考）
3. AI 声明与全文实际使用痕迹**一致**（不瞒报/漏报/虚假声明/用途不符）
4. AI 生成内容有**人工核验痕迹**（无未修改、未适配、纯 AI 段落）

## 二、AI 幻觉与数据真实性（4 项）

1. 数据完全源自赛题原题（无虚构/篡改/新增题目外数据/改精度）
2. 文献/结论/仿真数据真实（无编造虚假文献/结论/实验）
3. 图表/表格/拟合数值与原始计算**匹配**（无凭空造数）
4. 逻辑因果真实（无强行关联/虚假因果/无依据结论）

## 三、建模逻辑与题意适配（5 项）

1. 题意理解准确（无场景错配/题意误读/核心条件遗漏）
2. 建模逻辑自洽（假设/推导/求解前后一致，无矛盾/断裂/跳跃）
3. **全子问题闭环**（无漏题/空白作答/未求解/未回应）
4. 模型选型适配（无盲目堆砌高阶模型/通用模板）
5. 约束条件全部纳入（无脱离题目硬性条件）

## 四、求解结果合理性（3 项）

1. 结果符合常识/行业规律（无异常数值）
2. 求解方法与模型类型匹配
3. 关键参数取值有依据（无随意赋值）

## 五、官方写作规范（6 项）

1. 摘要合规：**单独一页、不跨页不溢出、800~1000 字**、含量化结果 + 核心模型 + 创新点、无空泛套话
2. 全文结构完整：题目/关键词/摘要/问题重述/问题分析/模型假设/符号说明/建模求解/结果分析/模型检验/优缺点/参考文献 全模块
3. 核心检验完整：**误差 + 灵敏度 + 稳健性** 三大必备
4. 内容呼应：摘要/结论/结果/建模过程前后一致
5. 模型假设 **4~6 条**、贴合题意、合理简化（无过度简化/无效/致命假设）
6. 无同质化：核心内容本题专属，无大面积通用套话

## 六、官方排版与页数（6 项）

1. 正文页数 **20~32 页（最优 25~30，不超 30）**（不含封面/附录）
2. 全局格式统一：字体/字号/行距/缩进/页边距统一（宋体小四 12pt / 1.5 倍行距 / 上下 2.54cm 左右 3.17cm），标题层级编号连续
3. 图表公式排版：三线表、图片高清、公式居中编号、图文对应
4. 匿名合规：全文无学校/姓名/队伍/隐私信息
5. 表格不跨页断裂（短表同页、长表跨页重复表头并标「续表X」）；全文无 >1/4 页异常空白/空白页
6. 图表尺寸协调：数据图 ≤12cm（半页）、流程图高 ≤9cm，无一图占满整页；图片插入 Word 已手动设尺寸并锁纵横比

## 官方硬性格式（2026 修订稿，详见 `02-红线与时间.md`）

- 电子版 = PDF 或 Word（建议 PDF），≤20MB，不压缩，第一页必须是摘要专用页
- 附录必含**全部可运行源程序**；缺源码/跑不通/结果不符 = 可能取消评奖
- 用 AI 则参考文献前设「AI 工具使用声明」，支撑材料含「AI 工具使用详情.pdf」
