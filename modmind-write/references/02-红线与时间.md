# 05 · 红线与时间（全程遵守）

## 1. 分工与合规红线

- **论文用户自己写**（AI 辅助 ≠ AI 代写），代码可 AI 写、可贴附录，正文是用户语言。
- **匿名**：全文禁止学校名、姓名、指导教师名、学号、Logo、赛区；代码注释、文档属性（作者/最后保存者）都要清。
- **查重 ≤ 20%**：问题重述必须改写、原理表述自主改写、图表/代码/仿真原创。
- **2026 AI 新规**（官方《人工智能工具使用规定》试行，违规 = 取消评奖）：
  - 核心建模与分析必须**参赛队主导**，AI 参与内容逐项人工审查核实。
  - 参考文献之前设「**AI 工具使用声明**」，二者择一：
    - 未用：「本参赛队在竞赛过程中未使用任何AI工具。」
    - 用了：「本参赛队在竞赛过程中使用了AI工具，主要用于【简要用途，如语言润色、代码调试等】，详细使用情况见支撑材料。」
  - 用了 AI → 支撑材料必含「**AI 工具使用详情.pdf**」，写 4 项：①工具名称/版本型号 ②使用目的与环节 ③提示方式与使用过程（可附交互示例）④对 AI 输出的采纳/人工修改/核验情况（语言润色除外）。
  - 隐瞒 / 虚假声明 / 未经审查直接提交 AI 核心内容 = **取消评奖资格**。

## 2. 论文格式硬红线（2026 修订稿）

- 电子版 = **PDF 或 Word（建议 PDF）**，≤20MB，不压缩；**第一页必须是摘要专用页**（承诺书/编号页不进电子版）。
- 摘要页：含标题 + 关键词（无需英文），原则上 ≤1 页；页码从摘要页起用阿拉伯数字「1」。
- 正文：第 4 页起、**无目录、≤30 页**；附录页数不限。
- 附录必含：支撑材料文件列表 + **全部完整可运行源程序**。缺源码/跑不通/结果与论文不符 = 可能取消评奖；没用程序要写明「本论文没有用到程序」。
- 引用他人/公开资料必须列参考文献并在正文标注。
- 支撑材料：RAR/ZIP ≤20MB，含可运行源程序 + 自主查阅数据（赛题原始数据除外）+ 大篇幅中间结果图表；文件列表放论文附录。

## 4. 72h 冲刺节奏（建议）

| 时段 | 任务 |
|------|------|
| 第 1 天（9/10 18:00 起） | 读题→选题→逐问判题型→建第一问模型→跑通第一问代码 |
| 第 2 天 | 第二三问建模+求解→画图→三类检验 |
| 第 3 天上午 | 完成正文、打磨摘要（改 ≥5 遍）、查格式 |
| 第 3 天下午 | MD5 → 提交 → **对照 `03-提交前自查.md` 26 项终检** |

> ⏰ 每天至少预留 2h 缓冲。**第 3 天 20:00 是 MD5 死线**，不是提交死线，别搞混。

## 5. 环境速记（Python 两个坑）

- 装包用 `py -m pip install xxx`（`py` 是 Python 3.14，有 pip）；裸 `python` 是 msys64 的、没 pip。
- 绘图脚本开头必加（否则中文变方框）：

```python
import matplotlib.pyplot as plt
plt.rcParams['font.sans-serif'] = ['SimHei']
plt.rcParams['axes.unicode_minus'] = False
```

- 数据/代码/图表/论文 四个文件夹分开，命名统一。
