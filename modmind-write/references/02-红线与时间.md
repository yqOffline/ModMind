# 05 · 红线与时间（全程遵守）

## 1. 分工与合规红线

- **论文用户自己写**（AI 辅助 ≠ AI 代写），代码可 AI 写、可贴附录，正文是用户语言。
- **匿名**：全文禁止学校名、姓名、指导教师名、学号、Logo；代码注释、文档属性（作者/最后保存者）都要清。
- **查重 ≤ 20%**：问题重述必须改写、原理表述自主改写、图表/代码/仿真原创。
- **AI 使用说明**：2026 要求附录写明 AI 使用情况。

## 2. 时间节点（2026 国赛，以官方通知为准）

| 节点 | 时间 | 动作 |
|------|------|------|
| 报名截止 | 9/7 20:00 | 确保已报名、拿到队号 |
| 出题 | 9/10 18:00 | 下载题目，选题（A/B/C） |
| 72h 比赛 | 9/10 18:00 → 9/13 20:00 | 建模+求解+论文 |
| MD5 上传 | 9/13 20:00 前 | 生成论文 MD5 并提交 |
| 提交 | 9/13 20:30 → 9/14 14:00 | 上传最终 PDF（无延长） |

## 3. 72h 冲刺节奏（建议）

| 时段 | 任务 |
|------|------|
| 第 1 天（9/10 18:00 起） | 读题→选题→逐问判题型→建第一问模型→跑通第一问代码 |
| 第 2 天 | 第二三问建模+求解→画图→三类检验 |
| 第 3 天上午 | 完成正文、打磨摘要（改 ≥5 遍）、查格式 |
| 第 3 天下午 | MD5 → 提交 → 终稿五步校验（内容/格式/细节/匿名/导出预览） |

> ⏰ 每天至少预留 2h 缓冲。**第 3 天 20:00 是 MD5 死线**，不是提交死线，别搞混。

## 4. 环境速记（Python 两个坑）

- 装包用 `py -m pip install xxx`（`py` 是 Python 3.14，有 pip）；裸 `python` 是 msys64 的、没 pip。
- 绘图脚本开头必加（否则中文变方框）：

```python
import matplotlib.pyplot as plt
plt.rcParams['font.sans-serif'] = ['SimHei']
plt.rcParams['axes.unicode_minus'] = False
```

- 数据/代码/图表/论文 四个文件夹分开，命名统一。
