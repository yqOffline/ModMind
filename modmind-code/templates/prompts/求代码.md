# 提示词模板 · 求代码（喂 AI 写求解代码）

> 用法：把【】里的占位换成你的内容。三个变体对应优化/统计/评价。写代码前先看 `references/03-喂AI速查.md`，能复用 `templates/code/` 就复用。

## 变体 A：优化题

```
我要用 [模型名：线性规划/整数规划/非线性/多目标/遗传算法] 求解一个数学建模优化题。

【数学模型】
决策变量：[变量]：[含义]，类型[连续/整数/0-1]，范围[上下界]
目标函数：max/min [完整方程]
约束条件：
1. [约束1]
2. [约束2]（含变量非负、上下界，一条不漏）

【数据】
数据在 [文件路径]，格式 [CSV/Excel]，列含义 [说明]（无数据删此行）

【要求】
1. 用 Python 的 [scipy.optimize.linprog / milp / minimize / networkx] 求解
2. 输出最优解、最优目标值、每个变量取值
3. 对关键参数做 ±10% 扰动，输出灵敏度对比表
4. 画出 [图类型]，展示 [对比内容]，中文绘图（SimHei）
5. 代码带详细注释，输出中间量供我核对
```

## 变体 B：统计题

```
我要用 [模型名：回归/PCA/聚类/分类] 求解一个数学建模统计题。

【任务】
特征 X：[列含义]；目标 y：[列含义]（分类题说明 0/1 各代表什么）
任务类型：[回归/降维/聚类/分类]

【数据】
数据在 [文件路径]，格式 [CSV/Excel]

【要求】
1. 先划分训练/测试集（7:3），再做标准化（防数据泄漏）
2. 回归：输出 R² + 各变量 p 值 + 残差图
   分类：输出 AUC + 准确率 + 混淆矩阵 + 5 折交叉验证
   聚类：先标准化 + 肘部法则定 k + 解释每簇含义
3. 做交叉验证 / 换模型对比
4. 画出 [图类型]，中文绘图（SimHei）
5. 代码带详细注释，输出中间量供我核对
```

## 变体 C：评价题

```
我要用 [AHP / 熵权法 / TOPSIS / 组合赋权 / 灰色关联] 求解一个数学建模评价题。

【指标体系】
指标1 [含义]，方向[越大越好/越小越好]
指标2 [含义]，方向[...]
...（方向逐个标清）

【权重方法】
[主观 AHP（附判断矩阵）/ 客观熵权 / 组合赋权]，理由：[...]

【要求】
1. 正向化 → 标准化 → 定权重 → 排序
2. 输出：权重表（和为 1）、排序结果、贴近度 C
3. AHP 算一致性 CR（要 <0.1）；熵权处理 ln(0)
4. 权重 ±10% 扰动，输出灵敏度对比表
5. 画出 [图类型]，中文绘图（SimHei）
6. 代码带详细注释，输出中间量供我核对
```

## 通用补充条款（可追加）

- 「先在小样本上跑通，再换全量数据」
- 「给出多方案对比（至少 2 种算法），说明为什么选这个」
- 「如果结果不合理，优先检查我模型是否写错，而不是怀疑代码」
