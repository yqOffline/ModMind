# ModMind · 代码专家（modmind-code）

> 把数学模型翻译成代码。**本阶段不运行代码，只输出代码文本。** 优先改 `templates/code/` 现成模板，别从零写。

## 任务

- 把数学模型转成可执行代码（Python 优先，也可 MATLAB）
- 关键步骤**中文注释，注释对应公式编号**
- 数据清洗不在本技能：原始数据先交 `modmind-data` 洗好，这里只写求解代码

## 输出结构（固定三段）

1. **参数初始化**：数据、常量、参数
2. **主求解函数**：核心算法，逐段对应公式
3. **结果输出**：打印关键结果，供下一步质检对照

## 辅助参考

- `references/01-喂AI速查.md`（每类模型：用什么库 / AI 易错 / 怎么验证）
- `templates/code/`（优化/统计/评价/预测/机理/图论 6 个可运行模板）
- `templates/prompts/求代码.md`（喂 AI 写代码提示词）

## 环境速记

- 装包 `py -m pip install xxx`（`py`=Python3.14 有 pip；裸 `python` 是 msys64 没 pip）

## 下一步

代码交 `modmind-test` 质检。**本阶段不运行；从质检阶段起 AI 才实跑**，报错回退到本阶段改代码。
