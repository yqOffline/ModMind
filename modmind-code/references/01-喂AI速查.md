# 03 · 喂 AI 速查（每类模型：用什么库 / AI 易错 / 怎么验证）

> 写代码前对照这张表。完整模板见 `templates/prompts/求代码.md`；可运行代码见 `templates/code/`。
> 本表管「怎么写 + 怎么验」；「选哪个模型」见 `modmind-model/references/01-模型选型.md`。

## 总表

| 模型 | 库 | AI 最容易犯的错 | 你怎么验证 |
|------|-----|----------------|-----------|
| 线性/整数/0-1 | `scipy.optimize.linprog`/`milp` | max 忘取负、整数当连续 | 手算 1 个点对照 |
| 非线性规划 | `minimize`(SLSQP) | 局部最优当全局 | 多起点跑对比 |
| 多目标 | 加权 / `pymoo` | 不归一化直接加 | 检查有无归一化 |
| 图与网络 | `networkx` | 有向当无向、TSP 硬求精确 | 检查节点/边数量 |
| ODE | `scipy.integrate.solve_ivp` | 符号写反、漏初值 | 逐条核对流入/流出 |
| PDE | 有限差分手写 | 差分不稳定爆炸 | 检查 dt/dx² 稳定性 |
| 回归 | `statsmodels` | 只给 R² 不给 p 值 | 要完整结果表 + 残差图 |
| PCA | `sklearn.PCA` | 忘记标准化 | 检查 StandardScaler |
| 聚类 | `sklearn.KMeans` | 忘标准化、k 拍脑袋 | 肘部法则图 + 簇解释 |
| 分类 | `sklearn.RandomForest` | 数据泄漏、只看准确率 | AUC/F1 + 交叉验证 |
| AHP | 手写 | 忘一致性检验 | CR<0.1 |
| 熵权法 | 手写 | 忘正向化、ln(0) 报错 | 权重和为 1 |
| TOPSIS | 手写 | 正负理想解取反 | C∈[0,1] |
| 组合赋权 | 手写 numpy | 拍脑袋 α=0.5 | 权重和=1、α 有依据 |
| 模糊综合评价 | 手写 numpy | 隶属度行和≠1 | 行和=1、用 M(·,+) |
| 机器学习评价 | sklearn | 数据泄漏、只看准确率 | AUC/F1 + 交叉验证 |
| 时间序列 | `statsmodels.tsa` | 不验平稳性、数据泄漏 | ADF + 留测试集 |
| GM(1,1) | 手写 | 不检验精度 | C/P 值 |
| 灰色关联 GRA | 手写 numpy | ρ 乱取 | ρ=0.5、与 TOPSIS 交叉 |
| DEA | 手写 LP / `pyDEA` | 投入产出方向反 | 效率值∈(0,1] |

## 三个万能检查（所有模型通用）

1. **方向对了吗**：max 还是 min？指标正向/负向？有向/无向？
2. **预处理了吗**：标准化？归一化？0 值处理？先划分再预处理？
3. **验证了吗**：留测试集？显著性/一致性/精度检验？手算 1 个点？

## 各板块一句话要点

- **优化**：「写清目标函数和约束完整方程，标 max/min，变量类型和范围」
- **微分方程**：「写清每个状态量 d/dt 方程，给参数和初值，数值解」
- **统计-回归/分类**：「先划分训练/测试集再预处理，回归要 R²+p 值，分类要 AUC/混淆矩阵」
- **统计-降维/聚类**：「先标准化！累计贡献率定 k（PCA）/肘部法则定 k（聚类），解释结果」
- **评价**：「正向化→标准化→定权重→排序，AHP 验 CR、熵权验权重和」
- **预测**：「数据多+周期用时间序列（验平稳），数据少+单调用 GM(1,1)（验 C/P）」

> 铁律：**AI 会一本正经地写错，用户永远对结果负责。** 让 AI 输出中间量（权重、系数、各步结果）供核对，别只给最终答案。
