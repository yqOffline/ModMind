# 02 · 模型选型（判完题型 → 选对模型）

> 按题型查决策表 + 背口诀。模型卡详见 vault `02-模型库/`。
> 本表管「选哪个模型」；选完写代码的「用什么库 + AI 易错 + 怎么验证」见 `modmind-code/references/01-喂AI速查.md`。

## 1. 优化类选型

| 判断 | 模型 | 求解库 |
|------|------|--------|
| 变量可小数、目标/约束全线性 | 线性规划 LP | `scipy.optimize.linprog` |
| 变量必须整数（人数/设备数） | 整数规划 IP | `scipy.optimize.milp` |
| 变量只取 0/1（选或不选） | 0-1 规划 | `milp` + bounds(0,1) |
| 目标/约束含平方/乘积/指数/根号 | 非线性规划 NLP | `scipy.optimize.minimize`(SLSQP) |
| 多个互相冲突的目标 | 多目标规划 | 加权归一化 / `pymoo` |
| 离散组合、路径、排序、指派 | 组合优化（智能算法） | GA / PSO / SA / `networkx` |

**口诀**：能小数式子直→LP；必须整数→IP；选或不选→0-1；平方乘积→NLP；又赚钱又省钱→多目标；排列组合找最优→组合优化。

## 2. 统计类选型

| 判断 | 模型 | 求解库 |
|------|------|--------|
| y 连续，找 X→y 影响/预测 | 回归分析 | `statsmodels` |
| 指标太多要降维 | PCA | `sklearn.PCA` |
| 无标签自然分组 | 聚类 | `sklearn.KMeans`(肘部法则) |
| 有标签判类别 | 分类 | `sklearn.RandomForest` |

**口诀**：y 连续→回归；指标多→PCA；没标签→聚类；有标签→分类。

## 3. 综合评价类选型（权重 + 排序两步）

**定权重**：

| 判断 | 方法 |
|------|------|
| 无数据、靠经验/专家 | AHP（一致性 CR<0.1） |
| 有量化数据、要客观 | 熵权法（ln(0) 加 0.0001） |
| 兼顾主客观（推荐） | 组合赋权 |

**排序/定级**：

| 判断 | 方法 |
|------|------|
| 量化数据、要排序 | TOPSIS（贴近度 C∈[0,1]） |
| 定性模糊语言 | 模糊综合评价 |
| 找「哪个因素影响最大」/小样本 | 灰色关联 GRA |
| 多投入多产出评效率 | DEA（CCR/BCC） |
| 大数据 + 有标签 | 机器学习评价 |

**高分组合**：AHP+TOPSIS（稳妥）· 熵权+TOPSIS（严谨）· 组合赋权（杀手锏）· 机器学习+传统对比（创新）。

## 4. 预测类选型

| 判断 | 方法 |
|------|------|
| 数据多、有周期/趋势 | 时间序列（先 ADF 验平稳，ARIMA） |
| 数据少、单调趋势 | GM(1,1)（验 C/P 精度） |

## 5. 机理类选型

| 判断 | 方法 |
|------|------|
| 物理/动力学规律、连续动态 | 微分方程 ODE/PDE |
| 找原因、算贡献度（非物理公式） | 因果归因（格兰杰/中介/SHAP） |
| 拆系统、理结构 | 结构方程 SEM |
| 反馈、长期宏观演化 | 系统动力学 SD |

## 6. 跨板块组合（高分进阶）

| 组合 | 场景 |
|------|------|
| 统计 + 评价 | 先聚类分档/PCA 降维，再 TOPSIS |
| 统计 + 优化 | 先回归拟合成本函数，再规划求解 |
| 统计 + 预测 | 回归/时序预测未来，再评价/优化 |
| 评价 + 优化 | 先用评价筛方案，再优化资源配置 |
