# 07 · B/C 题真题库（2020–2025 训练成果）

> 用途：9/10 出题后**对号入座**——「今年的 C/B 题像哪一年 → 直接复用那套模型链 + 代码模板」。
> 来源：本地真题库 `CSL/10-数学建模/05-资源/真题/`（2020–2025 六年真题+附件+优秀论文），已逐题精读训练。

## 0. 一句话结论（训练后的核心规律）

- **C 题 = 数据 + 统计/评价 + 预测 + 优化 的「四件套」复合题**。六年全部如此，几乎必考「量化分析/分类/评价 → 最优决策/策略」。
- **B 题 = 机理/几何/物理建模 + 优化**。先建方程（几何/物理/决策树），再数值求解/寻优，偏理工。
- **C 题通用模型链**：描述统计 → 相关性/降维 → 评价或分类 → 预测需求 → 优化方案 → 灵敏度分析。
- **B 题通用模型链**：机理方程 → 数值/解析求解 → 优化 → 误差/可靠性分析。

## 1. C 题逐年真题卡（核心）

### 2020C 中小微企业信贷决策
- **题型**：数据挖掘 + 分类(风险) + 评价(评级) + 优化(额度/利率)
- **模型链**：发票特征工程 → 分类器(Logistic/GBDT/XGBoost/RF/SVM + SoftVoting) → 信用评级 A~D → 流失率-利率回归 → 规划(额度/利率分配)
- **附件**：附件1 123家有贷(进销项发票) / 附件2 302家无贷 / 附件3 利率-流失率
- **坑**：①先划分再预处理(防泄漏) ②302家无标签→用123家模型迁移预测 ③D级原则上不放贷 ④国一都缺灵敏度分析→补上就是亮点
- **可练模板**：`统计.py`(classify) + `评价.py`(评级) + `优化.py`(额度)
- **精读**：`CSL/10-数学建模/04-真题与实战/论文精读-2020C中小微企业信贷决策.md`

### 2021C 生产企业原材料订购与运输
- **题型**：统计(供货特征) + 评价(重要性) + 优化(订购/转运) + 多目标
- **模型链**：描述统计 → 熵权/TOPSIS(选50家最重要供应商) → 整数规划(24周订购+转运) → 多目标(成本/损耗)
- **附件**：402供应商×240周 订货+供货 / 8转运商×240周损耗率
- **坑**：①库存≥2周产能 ②损耗率=(供货−接收)/供货 ③结果填附件A/B **勿改文件名**
- **可练模板**：`评价.py`(entropy+topsis) + `优化.py`(solve_ip)

### 2022C 古代玻璃成分分析与鉴别
- **题型**：统计(成分分析) + 聚类/分类(类型鉴别) + 预测(风化前成分) + 关联
- **模型链**：卡方/相关(风化 vs 类型/纹饰/颜色) → 成分数据预处理(累加85%~105%有效) → K-means/层次聚类(亚类) → 分类器(未知鉴别) → 回归(风化前预测)
- **附件**：表单1 文物信息 / 表单2 已分类成分% / 表单3 未知成分%
- **坑**：①成分累加≈100%约束 ②**明确要求敏感性分析**(必做)
- **可练模板**：`统计.py`(pca/kmeans/classify/regression)

### 2023C 蔬菜自动定价与补货 ⭐核心中的核心
- **题型**：统计(分布/相关) + 预测(未来一周需求) + 优化(补货+定价，收益最大)
- **模型链**：描述统计+相关性热力图 → 时间序列预测(ARIMA/GM(1,1)) → 规划(补货+定价, 损耗率纳入) → 灵敏度
- **附件**：附件1 6品类商品信息 / 附件2 销售流水(2020.7–2023.6, 3年) / 附件3 批发价 / 附件4 损耗率
- **坑**：①成本加成定价 ②可售单品总数27–33个 ③最小陈列量2.5kg ④收益=售价×销量−成本−损耗
- **可练模板**：`统计.py` + `预测.py`(arima/gm11) + `优化.py`

### 2024C 农作物种植策略
- **题型**：优化(整数规划) + 不确定性(模拟)
- **模型链**：整数规划(地块×作物×年份, 重茬/豆类轮作约束) → 蒙特卡洛/情景模拟(问题2不确定性) → 相关性+模拟(问题3)
- **附件**：附件1 34地块+20大棚 / 附件2 2023种植统计 / 附件3 result模板(result1_1/1_2/result2)
- **坑**：①重茬约束(同地块不连续同种) ②豆类3年至少1次 ③超产滞销/5折两种情形 ④2024–2030跨7年
- **可练模板**：`优化.py`(solve_ip)

### 2025C NIPT 时点选择与胎儿异常判定
- **题型**：统计(相关/回归+显著性) + 分组优化(聚类) + 分类(异常判定)
- **模型链**：相关性/回归(Y浓度~孕周+BMI, 显著性检验) → 分组(聚类+规划, BMI区间) → 分类器(女胎异常, Z值)
- **附件**：孕妇NIPT数据(列A~AE: 孕周/BMI/Z值/GC含量/读段数等26+列, 附列说明)
- **坑**：①Z值公式 Z=(X−μ)/σ ②女胎Y列空白 ③检测误差分析 ④4%浓度阈值
- **可练模板**：`统计.py`(regression/kmeans/classify)

## 2. B 题逐年真题卡（辅助）

### 2020B 穿越沙漠
- **题型**：动态规划 + 博弈 + 决策优化
- **模型链**：动态规划(单玩家最优策略) → 随机/博弈(多玩家)
- **坑**：天气已知/未知两种设定；结果填 Result.xlsx
- **可练模板**：`优化.py`(ga) + 现写 DP

### 2021B 乙醇偶合制备 C4 烯烃
- **题型**：统计(回归/方差分析) + 优化(寻优/实验设计)
- **模型链**：回归/方差分析(转化率、选择性~温度) → 拟合+寻优(收率最大, 温度<350) → 实验设计(再+5次实验)
- **坑**：收率 = 转化率 × 选择性
- **可练模板**：`统计.py`(regression) + `优化.py`

### 2022B 无人机纯方位无源定位
- **题型**：几何建模 + 优化(定位/调整方案)
- **模型链**：平面几何/三角(方位角定位) → 几何求解 → 优化(多轮调整)
- **坑**：纯方位几何关系；最少发射数
- **可练模板**：现写几何 + `优化.py`

### 2023B 多波束测线
- **题型**：几何建模 + 优化(测线设计)
- **模型链**：几何公式(覆盖宽度/重叠率) → 优化(最短测线 + 10%~20%重叠约束)
- **坑**：覆盖宽度公式；漏测/冗余权衡
- **可练模板**：现写几何 + `优化.py`

### 2024B 生产过程决策
- **题型**：统计(抽样检验) + 决策优化(期望成本)
- **模型链**：二项抽样检验(95%/90%信度) → 决策树/动态规划(检测/拆解, 期望成本最小)
- **坑**：期望成本；m 工序 n 零件推广
- **可练模板**：`统计.py` + 现写 DP/决策树

### 2025B 碳化硅外延层厚度
- **题型**：物理机理(光学干涉) + 数值计算
- **模型链**：薄膜干涉公式 → 数值求解(多光束干涉) → 误差分析
- **坑**：折射率非常数；多光束干涉；波数→波长换算
- **可练模板**：`机理.py` + 现写数值

## 3. 训练结论：模型频率 + 2026 预判

### C 题六年模型出现频率
| 模型/方法 | 出现年份 | 频率 |
|-----------|----------|------|
| **优化(规划/整数/多目标)** | 2020·2021·2023·2024 | **4/6 必考** |
| 回归/相关分析 | 2021·2022·2025 | 3/6 |
| 分类/聚类 | 2020·2022·2025 | 3/6 |
| 评价(TOPSIS/熵权/评级) | 2020·2021 | 2/6 |
| 预测(ARIMA/GM) | 2023(·2022风化前) | 1–2/6 |
| 蒙特卡洛/模拟 | 2024 | 1/6 |

> **C 题心法**：主体永远是「用附件数据建模 → 量化分析 → 优化出一个**可落地的决策/方案**」。优化是骨架，统计/评价/预测是血肉。

### B 题六年规律
| 年份 | 主题 | 机理类型 |
|------|------|----------|
| 2020 | 沙漠游戏 | 动态规划/博弈 |
| 2021 | 乙醇催化 | 化学实验+回归寻优 |
| 2022 | 无人机定位 | 平面几何 |
| 2023 | 多波束测深 | 立体几何 |
| 2024 | 生产决策 | 抽样检验+决策树 |
| 2025 | 外延层测厚 | 光学干涉 |

> **B 题心法**：主题跨物理/化学/几何/工程难以押题，但套路固定——「先建机理方程(几何/物理/决策) → 数值/解析求解 → 优化 → 双算法互证+特殊值校验+灵敏度」。

### 2026 预判与备战建议
- **C 题**：大概率仍是「贴近民生/产业的数据表 + 统计/评价/分类/预测 + 优化决策」复合题，且很可能含「预测需求 → 优化方案」链路。**主攻 C 题**。
- **主练**：2023C(最典型四件套) + 2020C(分类+评价) + 2021C(评价+优化)。
- **B 题**：辅助备选，若 C 题数据太难再转 B；B 题价值在「机理清晰、解法固定」，适合理工底子好的时候捡分。
- **赛前必做**：把 `统计.py`/`评价.py`/`预测.py`/`优化.py` 四个模板各跑通一遍自测，比赛直接改数据。

## 5. 优秀论文套路（B 题已提炼，C 题见下）

### B 题通用六步（来自 2023B 三篇国奖论文）
1. **先画图、建坐标系、定符号**，把机理翻译成几何量(正弦定理/相似三角形/向量叉乘/线面角是核心工具)。
2. **逐问递进、复用前问模型**，只重算新输入量(特殊→一般升维显式写出)。
3. **定义有歧义时并列建两个模型，用可观测事实/临界值选优**。
4. **机理题与优化题分治**：方向用命题证明+国家规范定，间距/参数用优化模型求，把二维决策拆成两个一维问题。
5. **检验 = 双算法互证 + 特殊值/对称性校验 + 灵敏度分析 + 物理直觉反证**。
6. **真实数据问先看地貌(画三维/等深线图) → 分区 → 逐区套前问模型**，输出总长/漏测占比/超限长度三个指标。

### C 题通用套路（来自 2023C 四篇国奖论文）

**共同高分点（6 条）**
1. **摘要三段式 + 数字锚点**：背景→方法→量化结果，每问一个具体数字(收益额/R²/品种数/关联度)，关键词列 3–6 个方法名。
2. **问题一 = 描述统计 + 分布 + 相关「三件套」**：描述统计(均值/标准差/偏度/峰度) → 直方图/折线图 → **相关性热力图**(Pearson/Spearman/偏相关/关联规则/聚类)。
3. **问题二 = 预测 + 规划「两段式」**：先预测未来需求(销量+成本)，再喂进利润最大化优化模型，定价成本加成、损耗率做进成本/约束。
4. **问题三 = 问题二的单品粒度变体**：0-1+连续混合变量，加 27–33 个、≥2.5kg 陈列约束，换混合变量算法(模拟退火/遗传/NSGA-II)。
5. **问题四 = 数据补采建议**：竞对价格、客流量、消费者反馈、天气/疫情、库存细分。
6. **检验意识是分水岭**：相关配 P 值、回归配 F/p/VIF、时序配 AIC/BIC、深度学习配扰动鲁棒性、双方法交叉验证。**±10% 灵敏度普遍缺失→补上就是亮点**。

**C 题通用「模型组合拳」五步**
```
① 数据清洗  自然连接→One-hot/时间聚合→3σ 或箱线图IQR去异常→剔退货/无关单品→分类(常年/季节/时令)
② 问题一    描述统计 + 分布直方图 + 相关性热力图（进阶：ACF定周期 / FP-Growth关联规则 / K-means聚类）
③ 问题二    定价关系(成本加成→双对数/Prophet求价格弹性) + 预测(ARIMA/VAR/LSTM/Prophet) + 规划(利润最大)
④ 问题三    VIKOR评需求度 → 0-1混合变量 → MIQP / NSGA-II 双目标(收益+需求满足)
⑤ 问题四    补采数据建议 + 动态规划/弹性理论收尾
```

**最值得抄进 skill 的三招（定价-预测-优化衔接点）**
1. **先预测、再喂规划**——预测结果作为优化模型的已知参数(四篇全部如此)。
2. **损耗率双落地**——既进单位成本 `B=C×(1+L)`，又进目标函数损耗项，再进约束上限。
3. **定价-销量显式建模**——不把销量当常数，用 `lnQ = lnQ预测 + Ep·ln(P/P预测)`(价格弹性) 或 Prophet 影响函数，让定价成为真正可优化的变量——这是 C 题得分上限的关键。

> 定价约束通用先验：**110% ≤ 定价/成本 ≤ 150%**（2023C 四篇一致）。
