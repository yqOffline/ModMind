# 01 · 题型判断（看到题 → 5 分钟定型）

> 目标：读题圈关键词 → 判断题型 → 知道去哪选模型。**复合题逐问判断，别整题套一个模型。**

## 1. 五大题型信号词

| 题型 | 关键词信号 | 特征 |
|------|-----------|------|
| 优化类 | 最优/最小成本/最大收益/调度/分配/路径/如何安排 | 一定有**决策变量** |
| 微分方程(机理)类 | 传播/变化率/随时间演化/传染/生态/机理/规律 | 需要物理/工程原理建方程，数据常用来**反演参数** |
| 统计类 | 相关/降维/分类/聚类/找规律/关系/影响 | 数据驱动，找关系/分组/判断 |
| 综合评价类 | 评价/排名/打分/优劣/选择/满意度/综合水平 | 研究对象 **≥2 个备选** |
| 趋势预测类 | 预测/未来/趋势/逐年变化 | 输入历史数据 → 输出未来数值 |

## 2. 问句关键词 → 题型（先看这个）

| 问句关键词 | 题型 |
|-----------|------|
| 最优方案、最大、最小、如何安排 | 优化 |
| 评估、比较、排序、优劣、综合水平 | 评价 |
| 预估、预测、未来走势 | 预测 |
| 机理、规律、演化过程 | 机理（微分方程） |
| 关系、影响、分类、识别、降维、聚类 | 统计 |

## 3. 决策树

```
看到题目
├─ 问「最优/最小/最大/安排/路径」
│   ├─ 全线性（钱、量按比例）→ 线性规划/整数规划
│   ├─ 有平方、乘积、指数、几何量 → 非线性规划
│   ├─ 既要…又要…（多目标权衡）→ 多目标优化
│   └─ 有节点、边、路径、流量 → 图与网络
├─ 问「随时间怎么变/传播/演化/扩散」
│   ├─ 只关心总量随时间变 → ODE（SIR/Logistic/牛顿冷却）
│   └─ 还关心空间分布（温度/浓度场）→ PDE（热传导/扩散）
├─ 问「什么关系/分类/降维/找规律」
│   ├─ y 是连续数 → 回归
│   ├─ 指标太多冗余 → PCA
│   ├─ 无标签自动分组 → 聚类
│   └─ 有标签判类别 → 分类
├─ 问「哪个好/排名/打分/选方案」
│   ├─ 先定权重：主观(AHP) / 客观(熵权) / 组合
│   └─ 再排序 → TOPSIS（AHP/熵权 + TOPSIS 串联）
└─ 问「未来会怎样/预测/趋势」
    ├─ 数据多、有周期 → 时间序列（ARIMA）
    └─ 数据少、单调趋势 → GM(1,1)
```

## 4. 复合题提醒（国赛常态）

国赛大题常有 3~4 问，每问可能不同题型。例：2020C = 分类 + 回归 + 多目标优化，逐问判断。
- **统计常是「中间件」**：评价题可能先聚类分档再评价；优化题可能先回归拟合成本函数再优化。看到统计关键词别急着独立成题，先想它是不是为大题服务。
- 判完题型 → 交给 `modmind-model`（读 `01-模型选型.md`）选模型。
