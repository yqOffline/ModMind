# 数据预处理速查（洗数据前看这张表）

## 1. 缺失值：按缺失比例选策略

| 缺失比例 | 策略 | 说明 |
|---|---|---|
| <5% | 直接删除该行 | 样本够多时最干净 |
| 5%~30% | 插补（数值→均值/中位数；类别→众数） | 中位数抗异常 |
| >30% | 该特征剔除 或 多重插补/模型预测 | 高缺失列信息太少 |

> 先想「为什么缺」：随机缺失可插补；非随机缺失（如高收入者不愿填）删或插补都会偏，需说明。

## 2. 异常值：先判断是真异常还是真信息

| 方法 | 做法 | 适合 |
|---|---|---|
| 3σ 法则 | 均值±3σ 之外 | 正态分布数据 |
| 箱线图 IQR | Q1−1.5·IQR ~ Q3+1.5·IQR 之外 | 偏态数据（更稳） |
| 业务判断 | 超过物理/业务上限 | 必做，最可信 |

处理：**删**（明确错误）/ **截尾**（不参与）/ **盖帽 Winsorize**（压到边界值）。
> 红线：真实极值（如疫情期销量暴涨）要**保留并解释**，不能为「好看」剔掉。

## 3. 正向化（统一「越大越好」）

| 指标方向 | 公式 |
|---|---|
| 越小越好（成本/污染） | 取倒数 x'=1/x 或取反 x'=max−x 或 x'=−x |
| 中间最好（区间型） | 到区间距离取负 |
| 越大越好 | 不动 |

## 4. 标准化 vs 归一化：看后续模型

| 后续模型 | 用什么 | 公式 |
|---|---|---|
| 距离类（KMeans/KNN/TOPSIS/PCA） | 标准化（去量纲） | z=(x−μ)/σ |
| 评价加权/熵权/灰色关联 | 归一化到 [0,1] | (x−xmin)/(xmax−xmin) |
| 梯度下降/神经网络 | 标准化 | 同上 |
| 树模型（RF/GBDT） | 可不做 | 对单调变换不敏感 |

## 5. 训练/测试集划分

- **先划分，再预处理**：StandardScaler 等要在训练集上 fit，再 transform 测试集，否则测试集信息泄漏进训练。
- 固定随机种子 `random_state=42`，保证可复现。
- 时序数据**不能随机打乱**，按时间切（前面训练、后面测试）。

## 6. 三查（交数据前）

1. 缺失/异常都交代了去处？
2. 正向化方向没搞反？
3. 预处理没有用到测试集信息？
