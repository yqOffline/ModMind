# 提示词模板 · 画图（论文用图）

```
我有一份数据，想画一张论文用的图。

【数据说明】
[数据结构、列含义、数值范围]

【图的要求】
- 类型：[折线图/柱状图/散点图/热力图/饼图/箱线图]
- X 轴：[说明]，Y 轴：[说明]
- 需要 [图例/中文标签/数据标注/单位]
- 用途：数学建模论文，请用规范样式（三线表风格、无边框冗余）

【额外要求】
1. 中文绘图：plt.rcParams['font.sans-serif']=['SimHei']; plt.rcParams['axes.unicode_minus']=False
2. 分辨率 dpi=300，尺寸 8-12cm × 6-9cm
3. 输出图片文件 + 完整代码
```

> 论文图规范：图标题在图下方居中、坐标轴含单位、单图不超过半页、≥300dpi。
